# 1. 创建一个名为 yolo 的环境，指定 Python 3.10 (目前最稳的版本之一)
conda create -n yolo python=3.10 -y

# 2. 激活这个环境 (激活后，命令行前面会出现 (yolo) 字样)
conda activate yolo

# 3. 在这个干净的环境里安装 ultralytics
pip install ultralytics

第二步：一行命令体验 (CLI 模式)
这是最快的方式。直接在终端输入：

Bash

yolo predict model=yolo11n.pt source=0 show=True
发生了什么？

model=yolo11n.pt: 它会自动下载最新的 YOLO11 Nano 模型（最小最快，适合体验）。

source=0: 调用您的电脑摄像头（如果是笔记本自带摄像头）。

show=True: 弹出一个窗口实时展示检测结果。

注：如果您没有摄像头，可以将 source=0 换成一张图片的路径，或者一个本地视频文件的路径。
